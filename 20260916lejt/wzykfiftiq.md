# 枣庄市妇幼保健院新院区成人预防接种门诊开诊啦

> 更新时间：2026-09-16 (UTC+8)

为满足日益增长的成人疫苗接种需求，近日，在薛城区卫健局和薛城区疾控中心的指导下，新院区狂犬暴露门诊升级为成人接种门诊，12月12日正式开诊。
**枣庄市妇幼保健院新院区正式开设成人接种门诊**
**提供以下成人疫苗的接种服务**

一、接种门诊地点：新院急诊科成人预防接种室。

二、接种时间:狂犬病疫苗为24小时，其他疫苗为8:30-11:30,13:30-17:00。

三、疫苗种类和接种人群：

1.新冠疫苗为3岁以上人群免费接种；

2.狂犬病疫苗为0岁以上人群收费接种；

3.双价人乳头瘤病毒疫苗（俗称2价宫颈癌疫苗）、乙肝疫苗、四价流感疫苗和23价肺炎球菌多糖疫苗均只针对18岁以上人群收费接种。

四、接种门诊详询电话：0632-8791153。

**疫苗简介**

**疫苗名称：双价人乳头瘤病毒疫苗（大肠杆菌）**

一、接种对象：9-45岁女性。

预防疾病：

1. 预防因高危型HPV16/18型所致的宫颈癌；

2. 2级、3级宫颈上皮内瘤样病变（CIN2/3）和原位腺癌；

3. 1级宫颈上皮内瘤样病变以及HPV16型、18型引起的持续感染。

二、免疫程序：

1. 推荐于0、1和6月分别接种1剂次，共接种3剂。第2剂次可在第1剂之后的1-2月内接种，第3剂可在第1剂后的5-8月内接种。

2. 对9-14岁女性也可以选择采用0、6月分别接种1剂次（间隔不小于5个月）的免疫程序。

三、接种禁忌及注意事项：

1. 对本品任一活性成分或辅料严重过敏者反应者；

2. 注射本品后有严重过敏反应者，不应再次接种本品；

3. 疫苗接种不能取代常规宫颈癌筛查，也不能取代预防HPV感染和性传播疾病的其他措施。

**疫苗名称：乙型肝炎疫苗**

疫苗规格：20ug、60ug

一、接种对象：16岁及16岁以上的乙型肝炎易感者。

免疫程序：

1. 20ug基础免疫程序为3针，分别在第0个月、第1个月、第6个月接种；

2. 60ug推荐无应答者接种1剂次（60ug），经采血确认其抗体水平未达到阳性者在考虑接种第2剂，两剂间隔至少4周以上。

二、接种禁忌及注意事项：

1. 已知对该疫苗所含任何组分，包括辅料、甲醛以及硫酸庆大霉素过敏者；

2. 患急性疾病、严重慢性疾病、慢性疾病的急性发作期和发热者；

3. 妊娠期妇女；

4. 患未控制的癫痫和其他进行性神经系统疾病者。

**疫苗名称：四价流感病毒裂解疫苗**

一、接种对象：3岁及以上人群，尤其推荐易发生相关并发症的人群，如儿童、老年人、体弱者、流感流行地区人员等。

预防疾病：流感病毒引起的流行性感冒；

免疫程序：于流感季节前或期间进行预防接种，成人接种1针。

二、接种禁忌及注意事项：

1. 发热、患急性疾病及感冒者；

2. 慢性疾病急性发作；

3. 有格林巴利综合征病史者；

4. 对鸡蛋过敏或其他过敏史者。

**疫苗名称：23价肺炎球菌多糖疫苗**

一、接种对象：2岁以上的易感人群。

预防疾病：预防在疫苗中含有的肺炎球菌型引起的肺炎、脑膜炎、中耳炎和菌血症等疾病；

免疫程序：每1次人用剂量为0.5ml。

二、接种禁忌及注意事项：

1. 对疫苗中的任何成份过敏者禁用；

2. 有发热、急性感染、慢性病急性发作者，最好推迟接种；

3. 妊娠期和哺乳期妇女，应推迟接种。
